# Stage 1 — Connecting tools

Not a skill, a connection checklist. Before anything below runs, connect
Taskmaster to:

- Your CRM
- GitHub (this repo)
- Email (Gmail/Google Workspace or your sending domain provider)
- LinkedIn
- Calendar
- CompanyEnrich (Stage 4)
- Lemlist (Stage 7)

Use Grok Bot's plugins panel + secure gateway for anything needing an API
key, never paste a key directly into a chat message.

`cold-email-kickoff/` in this folder is Taskmaster's own core skill, it
orchestrates ICP + lead magnet + strategy + plan in one flow and is what
Taskmaster reads first before delegating to any stage below.
